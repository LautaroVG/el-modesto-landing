# 🍷 Modesto - Bodegón de Bahía Blanca

Este es el sitio web oficial de **Modesto**, un bodegón moderno ubicado en Bahía Blanca. La página fue diseñada para ofrecer una experiencia visual impactante, permitiendo a los clientes acceder rápidamente a la carta, realizar reservas y pedir delivery.

## 🚀 Características

- **Diseño de Alto Impacto**: Seccion Hero con transiciones suaves y estética de bodegón clásico/moderno.
- **Menú Digital**: Integración de la carta completa en formato PDF.
- **Acciones Rápidas**:
  - Reservas directas vía **WhatsApp** con mensaje predefinido.
  - Integración con **PedidoYa** para delivery.
- **Responsividad Total**: Optimizado para dispositivos móviles y computadoras.
- **Stack Tecnológico**: React + Vite + Tailwind CSS.
